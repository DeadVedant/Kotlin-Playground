## 🛠️ How to Run

### Using Kotlinc Command Line:
```bash
# Compile Kotlin File
kotlinc 01-Basics-and-Syntaxes/Hello_World.kt -include-runtime -d HelloWorld.jar

# Execute JAR
java -jar HelloWorld.jar
```
